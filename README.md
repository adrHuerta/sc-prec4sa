# SC-PREC4SA

## Code
SC-PREC4SA is provided as a collection of R scripts. Step-by-step scripts for using and building a 1960-2015 station-based precipitation data for South America are provided in the script directory.

## Data
Collection data: https://doi.org/10.6084/m9.figshare.c.7588178.v4

## References
Huerta, A., Serrano-Notivoli, R., & Brönnimann, S. (2024). SC-PREC4SA: A serially complete daily precipitation dataset for South America. Scientific Data journal. https://doi.org/10.1038/s41597-025-05312-1
